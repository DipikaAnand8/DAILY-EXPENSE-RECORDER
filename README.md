
# Daily Expense Recorder

A simple Python-based console application to record and manage daily expenses.
This project helps users add expenses, view all recorded expenses, and calculate the total amount spent.

---

## Features

* Add new expenses
* View all saved expenses
* Calculate total expenses
* Simple menu-driven interface
* Beginner-friendly Python project

---

## Technologies Used

* Python 3

---

## How the Program Works

The program displays a menu with four options:

1. Add Expense
2. View Expenses
3. Total Expenses
4. Exit

Users can continuously perform operations until they choose the Exit option.

---

## Code Functionality

### 1. Add Expense

The user enters:

* Expense name
* Expense amount

The expense is stored in a list.

Example:

```python
expenses.append([name, amt])
```

---

### 2. View Expenses

Displays all saved expenses in the format:

```text
Food : Rs. 200
Travel : Rs. 150
```

---

### 3. Total Expenses

Calculates the total amount spent by adding all expense amounts.

Example:

```python
total += item[1]
```

---

### 4. Exit

Stops the program execution.
